# Discrete Operational Amplifier — Wideband, DC-Coupled

A **discrete-component operational amplifier**: no op-amp ICs, only
transistors, resistors and capacitors, assembled on a small board. The
design targets a genuinely hard combination of *high gain* and *wide,
DC-coupled bandwidth*.

---

## 1. Objective

| Parameter                | Target                                  |
|--------------------------|-----------------------------------------|
| Open-loop gain `Aol`     | **1000** (60 dB)                        |
| −3 dB bandwidth          | **10 MHz** (flat from DC upward)        |
| Coupling                 | **DC — no coupling capacitors**         |
| Supplies                 | ±15 V                                   |
| Input pair               | Low-offset RF BJT diff pair (BFP420)    |
| Output buffer            | Unity-gain NPN follower (BFP420)        |
| External load (for Aol)  | R7 = 10 kΩ (see §5e load derating)      |

### Why this is hard

Gain and bandwidth are linked through the **gain-bandwidth product**:

```
GBW = Aol x f_-3dB = 1000 x 10 MHz = 10 GHz
```

So a gain of 1000 flat to 10 MHz demands a **~10 GHz gain-bandwidth
product** from a discrete amplifier. For comparison, the discrete JFET
prototype below tops out near **34 MHz GBW** even with its compensation
capacitor removed — the intrinsic parasitic poles, not the compensation,
set the ceiling. Reaching 10 GHz GBW effectively requires GHz-`fT` RF
transistors and a topology whose high-impedance nodes are small and/or
cascoded — realised here as a **single-stage cascoded front-end with a
regulated (gain-boosted) cascode load**, see §5d.

(`sim/rf_final.py`) — a single-stage, fully self-biased, regulated-cascode
amplifier on BFP420 (NPN) / BFP520 (PNP):

```
 IN+ ─┐                          ┌───────────────┐   ┌──────────┐
      ├─ BFP420 diff pair ──────┤ regulated PNP ├───┤ BFP420   ├── OUT
 IN- ─┘   (Q1/Q2, tail Q10)      │ cascode mirror│   │ follower │  (Q8)
                                 │ Q3..Q7        │   │  + sink  │
                                 └───────────────┘   └──────────┘
```

| Ref    | Role                                   | SPICE name |
|--------|----------------------------------------|------------|
| Q1, Q2 | input differential pair (BFP420)       | Q1, Q2     |
| Q10    | input-pair tail current source         | Qtail      |
| Q3, Q4 | PNP mirror load (BFP520)               | Q3, Q4     |
| Q5, Q6 | mirror cascodes (BFP520)               | Q3c, Q4c   |
| Q7     | cascode helper — regulated gain boost  | Qh         |
| Q8     | unity-gain NPN output follower         | Q5         |
| Q11    | follower current sink                  | Qbuf       |
| Q9     | bias reference diode                   | Qb         |
| R1     | bias reference resistor (13k)          | Rbias      |

| R3     | tail emitter (1k)                      | Ret        |

| R5     | mirror reference degeneration (22)     | Re3        |

| R6     | helper load (15k)                       | Rc         |

### 3a. Rev B (JFET) — superseded study

Generated by `gen_sch.py`; kept for the compensation study in §5a.

```
 IN- ──┐                    ┌──────────────┐   ┌────────┐   ┌────────────┐
       ├─ JFET diff pair ───┤ cascoded PNP ├───┤ NPN    ├───┤ PNP VAS    ├─┐
 IN+ ──┘   (2SK209)         │ mirror load  │   │ buffer │   │ (Q16 cas)  │ │
                            └──────────────┘   └────────┘   └────────────┘ │
                                                     Miller Cc ────────────┘
                                                                           │
                        ┌───────────────┐   ┌────────────┐   ┌───────────┐ │
                        │ Vbe multiplier│───┤ class-AB   ├───┤ OUT       ├─┘
                        │ (Q12)         │   │ driver+out │   │ (Q7/Q8)   │
                        └───────────────┘   └────────────┘   └───────────┘
```

Stage by stage:

1. **Input pair** — matched N-JFETs `Q1`/`Q2` (2SK209 class; LSK170/LSK389
   are drop-in alternatives). `Q1` gate = **IN−**, `Q2` gate = **IN+**.
   `R12`/`R13` (1k) are input series resistors; `RT1` (1k trimmer) nulls
   input offset by trimming source degeneration.
2. **Active load** — PNP mirror `Q9`/`Q10` (BC860) with shared emitter
   resistor `R16` (4.3k); `Q13` cascodes the mirror output so the
   high-impedance node stays ~1 Vbe below VCC. `C7` (22p) drains the input
   drain node.
3. **Input buffer / VAS** — NPN emitter follower `Q11` isolates the mirror
   node from the VAS base current; `Q5`/`Q16` form the PNP common-emitter
   voltage-amplifier stage, with `Q16` cascoding its output (`n_vc` bias
   from divider `Rv1`/`Rv2`).
4. **Compensation** — Miller cap `C3` (12p) from the VAS input to the VAS
   output (`n_x -> n_q5c`), plus `C7` on the input drain. `GBW ≈ gm_eff /
   (2π·C3)`.
5. **Output bias** — `Q12` Vbe multiplier (`R17` 1.1k / `R18` 1k ≈ 1.4 V)
   with `C4` bootstrap.
6. **Class-AB output** — complementary emitter followers `Q7`/`Q8` with
   2.2 Ω emitter resistors (`R10`/`R11`) for thermal stability. `R9`/`R8`
   set the driver currents.

Notes:
- Supplies ±15 V; input/output brought out on `J1` (OUT / IN+ / IN− /
  +15 V / −15 V / GND).
- ERC is clean (see `erc.rpt`): 0 errors, 0 warnings.
- The board (`opamp.kicad_pcb`) is still just an outline — no layout yet.

## 4. Measurement methodology

A discrete amp with 60 dB+ gain cannot be measured open-loop by simply
driving the input: the output rails immediately. The bench instead:

1. **DC bias via offset injection** — `find_voff()` sweeps a small DC
   source on IN− to find the differential voltage that centres the output,
   then fixes IN− at that voltage.
2. **AC open-loop sweep** — drives IN+ with `AC 1`, runs `ac dec ... 1 20gig`,
   and probes `v(OUT)`.
3. **Metrics** — from the complex output the scripts compute:
   `Aol` (low-frequency gain), dominant pole `f_-3dB`, `GBW` (0 dB
   crossing), and `PM` (phase margin, unwrapped).

Used by both `sweep_cc.py` (schematic-linked, via `kicad_spice_run.py`) and
`rf_two.py` (standalone ngspice, real RF device models).

## 5. Results / current status

### 5a. JFET schematic (Rev B), Miller-cap sweep

`python3 sim/sweep_cc.py 12p 5p 2p 1p 0.5p 0.2p 0.1p 0.05p 0.02p 0.01p`

| C3    | Aol (dB) | dominant pole | GBW      | PM      |
|-------|----------|---------------|----------|---------|
| 12p   | 67.9     | 10.5 kHz      | 8.8 MHz  | 64°     |
| 5p    | 67.9     | 24.3 kHz      | 19.9 MHz | 22°     |
| 2p    | 67.9     | 58.8 kHz      | 27.2 MHz | −10°    |
| 1p    | 67.9     | 114 kHz       | 30.4 MHz | −22°    |
| 0.1p  | 67.9     | 728 kHz       | 34.1 MHz | −34°    |
| 0.01p | 67.9     | 1.55 MHz      | 34.5 MHz | −35°    |

**Reading:** with the *nominal* 12p cap the amp is well compensated
(PM 64°) but only 8.8 MHz GBW. Removing compensation raises GBW toward
~34.5 MHz but the phase margin goes negative (unstable) and the dominant
pole **saturates near 1.5 MHz** — an *intrinsic* pole, not the cap, is the
limit. The JFET front end therefore cannot reach 10 GHz GBW.

### 5b. RF two-stage front-end (BFP420 / BFP520), `rf_two.py`

Prototype replacing the JFET front end with GHz-`fT` RF BJTs:

| Variant                | Aol (dB) | GBW      | PM      |
|------------------------|----------|----------|---------|
| Miller Cc = 2p         | 66–71    | ~600 MHz | 64°     |
| Miller Cc = 0          | 71       | ~3.9 GHz | −75°    |

A real-RF-device two-stage gets **~600 MHz GBW when stably compensated**
and up to ~3.9 GHz uncompensated (unstable). The DC operating point is
fragile (the mirror must supply the second stage's base current). `rf_two`
is now a fallback; the single-stage cascode below is the primary path.

### 5c. RF single-stage cascoded front-end (BFP420 / BFP520), `rf_wide.py`

**This is the primary wideband design.** One high-impedance node only, so
`GBW = gm/(2·pi·C_out)` directly, and `f_-3dB = GBW/Aol`. Topology:

    NPN diff pair Q1/Q2 (BFP420)  ->  cascoded PNP mirror load (BFP520)
    ->  unity-gain NPN buffer Q5  ->  OUT

Key finding: a *cascoded* PNP mirror raises the load resistance without
adding a pole — but it needs the mirror base tied to the **cascode
collector** node (diode feedback around the cascode), not the bottom
device's collector. The naive version is bistable and collapses to ~0
current (an earlier `rf_frontend` variant read −28 dB for this reason).

Best-so-far (itail = 2 mA, vcp ≈ 13.2 V, Cp = 0.1 pF):

| Quantity        | Value                    |
|-----------------|--------------------------|
| Aol             | **58.1 dB** (806 V/V)    |
| f_-3dB          | **18.4 MHz**             |
| GBW (0 dB)      | 6.4 GHz                  |
| PM              | 37°                      |

- The -3 dB point (18.4 MHz) already **exceeds the 10 MHz target**, but the
  low-frequency gain is **~1.9 dB short of 60 dB**.
- `Aol` is bias-independent at ≈ 58 dB (intrinsic gain `gm·ro`); raising
  the tail current only raises GBW and *lowers* PM (itail = 4 mA →
  GBW 11 GHz but PM 19°). Adding an input-pair cascode breaks the mirror
  feedback and collapses the gain, so the load-side cascode is the ceiling
  of this topology.

### 5d. Regulated (gain-boosted) cascode — **target met**, `rf_wide.py rc=20k`

To break the 58 dB ceiling, the mirror cascode bias is made **self-regulating**
instead of fixed: a helper PNP `Qh` (emitter = VCC, base = the cascode emitter
`n2`) drives **both** cascode bases through a collector resistor `Rc`. This is
the classic *regulated cascode* / gain-boost: the helper senses the cascode
emitter and servos it, multiplying the cascode `gm` (and hence `ro`) by the
helper's gain.

     Qh vcph n2 VCC QP     Rc vcph -VCC 20k     cascode bases <- vcph

| itail | Rc  | Aol (dB) | f_-3dB  | GBW     | PM   | Vos    |
|-------|-----|----------|---------|---------|------|--------|
| 2 mA  | 20k | **62.0** | 15.8 MHz| 6.21 GHz| 54°  | 28 mV  |
| 2 mA  | 25k | 61.3     | 16.6 MHz| 6.37 GHz| 56°  | —      |
| 2 mA  | 15k | 63.0     | 13.9 MHz| 5.80 GHz| 51°  | —      |
| 3 mA  | 20k | 60.8     | 24.2 MHz| 8.70 GHz| 49°  | 23 mV  |
| 3 mA  | 25k | 60.3     | 24.6 MHz| 8.84 GHz| 50°  | —      |

**Recommended operating point: itail = 2 mA, Rc = 20 k, Cp = 0.1 pF →
Aol 62.0 dB, f_-3dB 15.8 MHz, GBW 6.2 GHz, PM 54°.** This clears the
60 dB / 10 MHz target with 2 dB of gain margin and 5.8 MHz of bandwidth
margin at a healthy phase margin. (itail = 3 mA trades margin for GBW:
60.8 dB at 24.2 MHz.)

**Bottom line: the 60 dB / DC-to-10 MHz target is now met** (regulated
cascode, §5d). Remaining polish: the helper is single-ended (senses only
`n2`), so open-loop Vos is ~25 mV — the RV1 emitter trim fixes it.

### 5e. Final self-biased design (Rev C, captured in the schematic) — `rf_final.py`

The ideal current sources of §5d are replaced by a real NPN bias mirror
(`Q9`/`R1`/`R2` → `vref`), `RV1` degenerates the output-mirror emitter for
offset trim, and the schematic's external load is `R7 = 10 kΩ`:

| RV1 (re4) | Aol (dB) | f_-3dB  | GBW     | PM    | Vos     |
|-----------|----------|---------|---------|-------|---------|
| 15 Ω      | 62.1     | 12.8 MHz| 5.69 GHz| 51.5° | 34.3 mV |
| 25 Ω      | 60.7     | 13.7 MHz| 6.20 GHz| 57.8° | 21.0 mV |
| **30 Ω**  | **60.2** | **13.8 MHz** | **6.25 GHz** | **59.9°** | **16.2 mV** |
| 35 Ω      | 59.8     | 13.7 MHz| 6.29 GHz| 61.6° | 11.9 mV |

**Recommended `RV1 ≈ 30 Ω` → Aol 60.2 dB, f_-3dB 13.8 MHz, GBW 6.25 GHz,
PM 59.9°, Vos 16.2 mV.** Trim range spans `RV1 = 15 Ω` (Vos 34.3 mV,
Aol 62.1 dB) to `70 Ω` (Vos −7.4 mV, Aol 58.4 dB); Vos nulls near
`RV1 ≈ 55 Ω`.

**Load derating.** The follower's input impedance `(β+1)(re+RL)` loads the
high-impedance node `c2`, so `Aol` depends on the external load:

| RL   | 500  | 1k   | 2k   | 5k   | 10k  | 20k  |
|------|------|------|------|------|------|------|
| Aol  | 53.4 | 56.4 | 58.3 | 59.7 | 60.2 | 60.4 dB |

`Aol ≥ 60 dB` therefore requires **RL ≥ ~10 kΩ**. (A Darlington output buffer
restores `Aol` at RL = 1 kΩ but adds a slow pole that collapses PM to 7° —
rejected.) The plain `rf_final.py` default of `RL = 1 kΩ` is why it prints
56.4 dB; the 60.2 dB figure uses the schematic load `RL = 10 kΩ`.

## 6. Open problems / work in progress

- **Input offset of the regulated cascode** — the helper `Q7` senses only
  the output-side cascode emitter `n2`, so the correction is single-ended
  and open-loop `Vos` is ~16 mV (vs ~8 mV for the plain cascode). The RV1
  emitter rheostat trims it (nulls near `RV1 ≈ 55 Ω`); a symmetric helper
  added nothing (the offset is intrinsic to the single-ended servo).
- **Phase margin** — PM 54° at the recommended point is healthy; going to
  itail 3 mA (higher GBW) drops it to ~49°, still stable.
- **DC bias robustness (`rf_two`)** — interstage node is set by a resistor
  against the second stage's base current; the two-stage variant remains a
  fallback and needs a DC-stable bias scheme.
- **Stability vs. load** — the output buffer + compensation need a check
  across capacitive loads.
- **Schematic/PCB capture** — the winning regulated-cascode topology is now
  captured as Rev C (`gen_sch_rf.py` → `opamp.kicad_sch`), ERC-clean with the
  netlist matching `sim/rf_final.py`; `opamp.kicad_pcb` is still outline-only
  (no layout yet).
